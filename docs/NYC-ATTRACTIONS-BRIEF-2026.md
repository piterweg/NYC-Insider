## PART D — Weather widget + local time

**Open-Meteo** is the right choice: free, no API key, no signup, CORS-enabled, JSON. One call gets current conditions plus a 3-day forecast in NYC local time:

```
https://api.open-meteo.com/v1/forecast?latitude=40.7128&longitude=-74.0060&current=temperature_2m,apparent_temperature,precipitation,weather_code,wind_speed_10m&daily=weather_code,temperature_2m_max,temperature_2m_min,precipitation_probability_max&timezone=America%2FNew_York&forecast_days=3&temperature_unit=fahrenheit
```

Verified live 2 Nov 2026 — returns `current.temperature_2m`, `daily.time[0..2]`, and `utc_offset_seconds: -18000`. Add `&temperature_unit=fahrenheit` for °F (default is °C); `weather_code` is WMO — map 0/1/2/3 clear→cloudy, 45/48 fog, 51–67 rain, 71–77 snow, 95–99 storm.

**Local time** — never use the browser clock; derive it from the IANA zone:

```js
const fmt = new Intl.DateTimeFormat('en-US', {
  timeZone: 'America/New_York',
  weekday: 'short', hour: 'numeric', minute: '2-digit', hour12: true
});
fmt.format(new Date()); // "Mon, 3:02 PM"
```

For a machine-readable offset use `Intl.DateTimeFormat('en-US',{timeZone:'America/New_York',timeZoneName:'shortOffset'})` → `GMT-5`/`GMT-4`, and format the API's `current.time` string as a *floating* local time (it is already America/New_York — do not run it through `new Date()` or it will shift by the viewer's zone).

Source: https://open-meteo.com/en/docs · https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Intl/DateTimeFormat
